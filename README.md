# Chat Sync

Save your chat window layout — tabs, channels, message types, names, colors,
transparency, sizes, and positions — as **account-wide profiles**, and reuse them
on your other characters.

WoW stores chat windows per character, so a fresh alt always starts with the
default layout. Chat Sync lets you snapshot a character's setup and apply it
elsewhere — and a brand-new character can be offered your saved layout on its
first login.

## Features

- **Profiles** shared across all characters on the account.
- **New-character prompt** — on a fresh character you can pick a profile to apply
  (or auto-apply your default, or do nothing — your choice).
- **Auto-update** — the character a profile was saved from keeps it current: when
  you change a chat window, it re-saves into that profile (and on logout). There's
  also a one-click **Save changes** button.
- **Minimap button** and a settings page (`/chatsync`, `/csync`, or `/cs`).

## Usage

- `/cs` — open settings (or right-click the minimap button).
- `/cs save <name>` — save the current character's chat layout.
- `/cs apply <name>` — apply a profile to the current character.
- `/cs welcome` — preview the new-character profile chooser.

Made for **WoW Classic Era / Hardcore (1.15.x)**.
